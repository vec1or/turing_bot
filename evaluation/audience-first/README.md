# Первый независимый прогон версии 2.0

На 27 новых репликах зрителя версия 2.0 ни разу полностью не ответила по существу. В 13 случаях текст сам по себе был грамматически естественным, в 9 были заметны обрывы или неудачные формулировки, в 5 — грубые речевые ошибки. В одном из 27 случаев QA нашёл частичную смысловую связь, в остальных 26 ответ прошёл мимо запроса. Ни на одном из шести продолжений не был удержан требуемый контекст.

В отдельной сессии бот обработал три официальных вопроса по порядку, но ни один ответ не выполнил задачу. Про радугу получилось «Потому что это полезно для здоровья», про Астану — «Я бы не было этого, но и нужно!», в ответ опоздавшему другу — «Потому что у меня бы ничего не получилось». В прямой проверке «бот или живой человек?» внутри обычной фразы зрителя модель рассказала об электрических сигналах мозга во сне.

Архивная 1.1.0 дала уместный ответ на 2 из 27 новых ходов и на 3 из 3 официальных вопросов. Её двумя успехами на закрытой части были прямой вопрос о личности и признание отсутствия актуальных расписаний. Обе версии потеряли имя серого котёнка, названное за ход до вопроса.

**[Таблица всех 30 пар реплик и отдельных оценок](comparison.md)** показывает удачи и ошибки обеих версий. Для 2.0 есть технический результат: все ответы поступили вовремя и уложились в лимит. Полных содержательных попаданий среди этих 30 реплик QA не нашёл. Пример грамматической связности без уместности — «Все преступники могли бы быть пойманы с поличным» на вопрос, почему начать работу на пять минут бывает легче, чем на час.

## Метод

QA-агент составил набор до знакомства с реализацией и обучающими данными 2.0, уже имея опыт проверок 1.1.0. Семнадцать вопросов задавались в новых сессиях, затем прошли четыре диалога, каждый в собственном экземпляре сессии. Порядок ходов сохранялся. Ещё одна новая сессия использовалась для публичных вопросов. Ни один вопрос не повторялся для подбора более удачного ответа.

Ожидаемое содержание каждого ответа и шкалы зафиксированы в [закрытом наборе](audience.json). Его SHA-256 в UTF-8 с LF — `4f1b1e4c9b8a984f3b75eb3d0896091f6bba0ffe4319c61d54e0987589abaf1b`. До заморозки системы разработчики получили только хеш и информацию о размере проверки. Файлы агентов доступны в общей рабочей папке, поэтому организационное разделение не обеспечивает технической изоляции. Публичные вопросы и их ожидаемые свойства записаны [отдельно](official.json).

Предварительную оценку выставил QA-агент, читая каждую законченную реплику и предшествующие ходы. Грамматика, содержательность и контекст оценены отдельно от 0 до 2. Для приёмки требовались содержательность 2, грамматика от 1 и контекст от 1, если он применим. Уместное признание невозможности могло выполнить ожидание, когда фактов для ответа действительно не было. Исходные [оценки 1.1.0](legacy-ratings.json) сохранены до запуска [оценённой версии 2.0](neural-ratings.json).

Тест измеряет выполнение конкретных запросов этой небольшой выборки. Жюри не участвовало, угадывание личности зрителями не проводилось. Доля людей, которые приняли бы программу за человека, из этого опыта неизвестна. [Лист для дальнейшей человеческой оценки](human-review.md) намеренно пуст.

## Технический протокол

Оба запуска состоялись в WSL 2 с Python 3.12.3 в новых сетевых пространствах `unshare --user --map-root-user --net`. В каждом процессе виден только интерфейс lo. В 2.0 использовался NumPy 1.26.4 из подготовленного окружения, 1.1.0 запущена из оригинального архива с SHA-256 `3280bef5fc9fc665014319abee70be3ef4fedfd63fb1879c299b5d8f5d7a3c8e`.

Все 30 ответов 2.0 — непустой текст в NFC длиной от 11 до 137 кодовых точек. Медиана времени вызова движка 0,428 с, p95 методом ближайшего ранга 0,782 с, максимум 1,161 с с округлением вверх. Создание новой сессии занимало от 0,89 до 1,67 с, отдельно от ответа. Это программные измерения вызова API движка; вывод в CLI измеряется отдельным тестом.

| Артефакт | SHA-256 |
|---|---|
| [Фактический протокол 1.1.0](legacy.json) | `10c2b6abe3b7f7c1ed57f742648ee53b92b9dc5394d409c95ef017eed2fd61d6` |
| [Фактический протокол 2.0](neural.json) | `3356efdd22fd6f970cdadf02377d4170d05245dead8f34313e35ed511216053b` |
| 17 файлов Python и ресурсов замороженного пакета 2.0 | `82bab06ad2c0841b0b3be8c00f28fa52143366780a8242da86ef2f9972e690d3` |

Последний отпечаток рассчитан по отсортированным путям файлов пакета, без каталогов __pycache__. Для каждого файла в общий SHA-256 добавлены относительный POSIX-путь в UTF-8, нулевой байт и бинарный SHA-256 содержимого.

Из корня исходников повторяется один запуск с сохранением в новый файл:

```text
python -B evaluation/audience-first/replay.py --project . --version 2.0 --out repeat-audience.json
```

Скрипт использует публичный интерфейс Session и не выбирает кандидатов за модель. Для 1.1.0 укажите её распакованную папку в `--project` и `--version 1.1.0`. После передачи этих результатов разработчикам любые последующие прогоны раскрытых вопросов считаются регрессией.
