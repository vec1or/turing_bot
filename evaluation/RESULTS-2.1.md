# Результаты версии 2.1.2

В последней заранее закрытой серии QA-агент признал уместным **1 ответ из 24**, в том числе в непрерывном раунде. Из 24 реплик **15 (62,5%)** пришли из общего резерва. Человеческого голосования не было. Доля резервных ответов превышает пожелание участника в 20–30%. Это работоспособный локальный прототип; качество свободного разговора пока недостаточно для уверенного выступления.

## Сравнение по содержанию

| Серия | 2.0.0 | 2.1.1 | 2.1.2 |
| --- | ---: | ---: | ---: |
| 28 вопросов, закрытых для 2.1.1, позднее использованных для повторной проверки | 0/28 | 3/28 | 5/28 |
| 24 новых вопроса, закрытых для всех трёх сборок | 0/24 | 1/24 | 1/24 |

На новых 24 в непрерывном раунде у 2.1.2 было 0 встречных вопросительных знаков и 0 повторных строк. В режиме со сбросом после каждого вопроса оказалось четыре повтора. Смысл ответа проверяли отдельно. Например, на вопрос о свободном часе студент предложил, чем займётся, а на запрос про три похожих кабеля генератор выдал грамматически и содержательно слабую реплику. Новая статистика тематических ассоциаций иногда подбирает чужую тему. На 38 ранее раскрытых вопросах промежуточная 2.1.1 выполнила 35 задач. Этот результат относится к проверке известных ошибок.

## Открытые примеры по отзыву пользователя

Составлены 18 вопросов по описанным пользователем конструкциям. Исходный лог из 17 реплик не был приложен к отзыву. На одинаковых 18 вопросах доля ответов с вопросительным знаком изменилась с 14/18 до 0/18. В 2.1.2 общий резерв сработал в 2/18 случаях — на двух выдуманных терминах. Маршрут ответа сам по себе не оценивает его уместность. Кавычки вокруг «Сова или жаворонок?» не изменили выбор. На просьбу назвать три причины срыва срока бот перечислил три разных фактора.

## Запуск и автономность

| Система | Вопросов | Медиана после ввода | Максимум | Максимальная длина |
| --- | ---: | ---: | ---: | ---: |
| Windows, CPython 3.11.9 x64 | 23 | 0.007 с | 3.690 с | 160 |
| Ubuntu WSL, CPython 3.12.3 | 23 | 0.003 с | 1.018 с | 160 |

Вывод и маршруты совпали во всех 23 позициях. В начале последовательности проверены три ранее известные формулировки из официального DOCX. Бот объяснил появление радуги, дал зимний совет и принял извинение. Лимиты 45 секунд и 300 символов соблюдены на каждом измеренном вопросе. Вопросительный знак в поле ответа отсутствовал. Техническая серия включает длинный ввод, эмодзи, пустую пару кавычек, повтор неизвестного термина и сброс раунда.

В обеих системах созданы чистые окружения и установлен NumPy 1.26.4 из wheelhouse с `--no-index`. При вызове обычной консоли в процессе теста установлен аудит Python, отклоняющий сетевые обращения. В WSL процесс дополнительно изолирован на уровне ядра; доступен только интерфейс lo. Сетевые адаптеры Windows во время проверки были включены. Для конкурсного видео участнику предстоит отдельно продемонстрировать физическое отключение сети.

Из 58 модульных тестов в Windows выполнены 56, два сравнения с PyTorch пропущены в игровом окружении. В обучающем окружении Ubuntu WSL выполнены все 58. Воспроизводимость статистики для продолжения фразы проверена повторным обучением в Windows по тому же тексту, что в WSL. SHA-256 распакованного JSON совпал: `e8b4c7c0146286f440333998e19eedc3b7c90d9a84f4e7dc298b36b9ee2f718f`.
