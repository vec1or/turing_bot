# Короткие социальные реплики

`Social.propose` предлагает реплику, когда собеседник здоровается, обращается к кому-то, благодарит, извиняется, прощается или поздравляет. При пересказе компонент ищет и сам речевой акт, и явную просьбу предложить ответ. Фактический вопрос после приветствия передаётся остальному боту.

## Происхождение и обучение

Использованы уже зафиксированные для проекта источники. После исключения ID предложений современной валидации осталось 23 059 русских строк Tatoeba CC0. Дополнительно использованы 26 159 уникальных пар из обучающих разделов базовой и современной смеси. Сюда входят 18 624 пары RusDraCor, 901 OASST1, 14 Russian Everyday Dialogues, 592 диалога и 6 028 продолжений Tatoeba. Для продолжений одного автора программа учитывает встречаемость выражений. Для явно разделённых реплик разных говорящих она также учитывает непосредственные ответы. [Источники, лицензии и способы получения](../DATA_SOURCES.md)

Правила русского языка выделяют тип обращения, форму вежливости, время суток и маркеры пересказа. Для отбора корпусных реплик заданы слабые лексические признаки благодарности, утешения, прощания и внимания. Авторское решение сопоставляет извинение с успокоительной репликой, а поздравление с благодарностью. Из подходящих реальных высказываний программа извлекает начальные слова, пунктуацию и переходы по двум предыдущим токенам. Словесное наполнение ответов приходит из корпуса. В компактном ресурсе хранятся числа наблюдений и переходов. При декодировании завершаются только последовательности с наблюдавшимся концом высказывания.

Наблюдение в таблице — сочетание последовательности токенов и опубликованной группы источника. Правая колонка показывает, сколько таких наблюдений дополнительно поддержано реальной соседней репликой. При обучении условных переходов наблюдаемая пара получает дополнительный вес 12. Одинаковая пара из нескольких снимков учитывается один раз.

| Входной акт | Наблюдения подходящей формы | Наблюдаемые пары |
| --- | ---: | ---: |
| Неформальное приветствие | 16 | 1 |
| Вежливое приветствие | 13 | 1 |
| Утреннее / дневное / вечернее приветствие | 4 / 6 / 6 | 1 / 1 / 1 |
| Обращение для привлечения внимания | 10 | 0 |
| Благодарность | 4 | 1 |
| Извинение | 13 | 0 |
| Обычное / окончательное прощание | 8 / 20 | 0 / 1 |
| Пожелание спокойной ночи | 5 | 0 |
| Поздравление | 39 | 0 |

Ответы на извинения и поздравления, обращения и часть прощаний опираются на отдельные засвидетельствованные формулы. Оценка для них ниже. Короткое «Всё в порядке» предполагает, что говорящий готов принять извинение. Явное нежелание простить, отрицание события и противоречащие ему оговорки служат основаниями воздержаться. Сложное отношение человека к произошедшему модель надёжно определить не может.

После подготовки `prepared/` и `modern/` выполните из корня проекта команду ниже. Она проверяет SHA-256 всех четырёх источников.

```text
python training/train_social.py --train modern/train.jsonl --valid modern/valid.jsonl --base-train prepared/train.jsonl
```

Windows Python и Ubuntu WSL воспроизвели `turing_bot/assets/social.json.gz` размером 1 300 байт, SHA-256 `9c78828ebc05c6936894f0f8dda1bd84863dfe1dd2fb7973be3ccba5c3de704a`.

## Пробы разработчика

После настройки отдельно проверены 19 новых вводов. Во всех 11 примерах прямого обращения или явного запроса совета компонент предложил реплику. На восьми нерелевантных вводах он воздержался. Проверялась применимость компонента, его внутренние оценки эвристические. Человеческое жюри в этом прогоне не участвовало.
