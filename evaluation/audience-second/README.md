# Вторая заморозка и новая независимая проверка

**На 14 новых репликах зрителя бот полностью не выполнил ни одного ожидания.** Архивная версия 1.1.0 на тех же вопросах выполнила два. У 2.0 в пяти случаях русский текст звучал естественно, в девяти был понятен с заметными шероховатостями. Тринадцать из четырнадцати ответов содержали обратный вопрос. Чаще всего бот просил пояснить уже ясное слово. Технически все запуски уложились в ограничения.

| Статус | Что проверялось | 1.1.0 | 2.0 в этом прогоне |
|---|---|---:|---:|
| Новый закрытый набор | 14 реплик, включая три двухходовых диалога | 2/14 | 0/14 |
| Регрессия раскрытой части | Первые 27 вопросов и диалоговых ходов | 2/27 | 1/27 |
| Публичная приёмка | Три официальных вопроса в отдельной общей сессии | 3/3 | 2/3 |

Первый генеративный кандидат получил 0/27 и 0/3 на публичных вопросах. Его протокол [сохранён отдельно](../audience-first/README.md). После передачи этих ошибок разработчикам прежний набор больше не служит независимой оценкой. Показатель для новой выборки характеризует маленькую авторскую проверку. Слепая игра с человеческим жюри не проводилась, и вероятность быть принятым за человека неизвестна.

## Что произошло в беседе

На прямой вопрос из зала о том, за ширмой живой участник или программа, финальная сборка ответила «Что ты имеешь в виду под словами „обращаюсь“?». На просьбу описать запах джаза в выдуманном городе ответила «В предложении». В диалоге о двух выдуманных пирогах не смогла выбрать пирог с яблоком по сведениям из самой реплики. На просьбу назвать начинку другого пирога спросила, что означает «начинкой». Когда пользователь явно сменил тему с историй на неизвестный фильм, программа перенесла переспрос в новую тему, но не запросила признаков фильма.

| Ось | Новые 14, оценки 0 / 1 / 2 | Регрессионные 27, оценки 0 / 1 / 2 | Официальные 3, оценки 0 / 1 / 2 |
|---|---|---|---|
| Грамматика и естественность | 0 / 9 / 5 | 0 / 15 / 12 | 0 / 0 / 3 |
| Содержательность и привязка | 2 / 12 / 0 | 2 / 24 / 1 | 0 / 1 / 2 |
| Удержание контекста на продолжениях | 2 / 1 / 0 | 5 / 0 / 1 | 0 / 0 / 2 |

В повторе прежнего набора улучшилось поведение на вопросе про букву на невидимой записке: бот адресно признаёт, что не знает написанную букву, и запрашивает информацию, хотя путает местоимение. На просьбу придумать имя кактусу всё ещё просит объяснить «только одно». Полные данные, оценки и дополнительно заготовленные бланки для человека доступны [для новых 14](second/comparison.md), [для прежних 27 и публичной тройки](comparison.md), [для человека на новых репликах](second/human-review.md) и [на прежних и публичных](human-review.md). Человеческая оценка не выполнена.

## Публичные вопросы

1. «Радуга возникает из-за того, что солнечный свет преломляется и отражается каплями воды, парящими в атмосфере». Физический механизм назван по теме. До запуска критерием было объяснить также разделение света на цвета. Эта часть в ответе отсутствует, поэтому содержательность 1/2.
2. «Оденься потеплее. Климат Астаны — резко континентальный с засушливым летом и холодной, снежной зимой». Уместный зимний совет, содержательность 2/2.
3. «Всё в порядке». Приемлемая короткая реплика непосредственно другу, содержательность 2/2.

## Методика и время

Второй набор написал QA-агент после знакомства с провалами первого. До чтения следующей доработки он зафиксировал [14 вопросов и их ожидания](second/audience.json), SHA-256 `be99ba69f517cbce415fa1b6b49ea2aab8be436c5a03d3f0362457519913026d` (UTF-8, LF). До заморозки разработчики получили только хеш и размер выборки. Вопросы составлены агентом, не зрителями мероприятия. Каждый одиночный вопрос и каждый отдельный диалог получили свежее состояние, без повторного выбора реплик.

Обе серии этой сборки выполнялись параллельно двумя процессами в WSL 2, Python 3.12.3, NumPy 1.26.4. Каждый процесс работал в своём сетевом пространстве только с интерфейсом lo. На всех 44 ходах получен непустой текст в NFC длиной 14–120 кодовых точек. Медиана времени одиночного вызова движка — 0,470 с, p95 ближайшего ранга — 0,871 с, максимум — 0,912 с с округлением вверх. Создание новой сессии занимало 2,81–4,15 с. Это время API движка, вывод интерфейса измеряется отдельно.

Отпечаток проверенных 31 файлов исходников и ресурсов пакета — `016f66fd10adc9ebb1c7226ff836bd4f595bd1a825d125ddca33b6059148040b` по алгоритму из первого отчёта. [Протокол второй заморозки на 27+3](neural.json) и [на новых 14](second/neural.json) сохранены вместе с [архивной 1.1.0 на новых 14](second/legacy.json). При любых последующих исправлениях оба этих набора уже считаются раскрытыми.

Для повтора из корня распакованного проекта используйте отдельные новые имена файлов:
