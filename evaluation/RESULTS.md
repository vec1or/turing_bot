# Результаты проверки версии 2.0.0

Программа запускается автономно на CPU и выдержала технические ограничения на проверенных входах. Способность вести свободный разговор с публикой остаётся недостаточной. В новой независимой серии из 14 ходов ни одна реплика полностью не выполнила содержательный критерий. В 13 случаях программа переспросила или признала нехватку сведений. Судил независимый агент по заранее записанным ожиданиям. Голосование людей за ширмы не проводилось.

## Платформы и измерения

Один и тот же сценарий из 22 вопросов прошёл через настоящий CLI в чистом окружении каждой ОС. Python и NumPy работали локально. Вывод всех 22 реплик посимвольно совпал. Для замера времени вопрос уже введён; отсчёт завершается после вывода реплики. Первоначальная загрузка модели в эту величину не входит. В сценарии есть длинный ввод, одна строка со знаками пунктуации и эмодзи, переключение темы и продолжения диалога.

| Условие | Python | Медиана, с | p95, с | Максимум, с | Самая длинная реплика |
| --- | --- | ---: | ---: | ---: | ---: |
| Windows x64, сборка 26300, обычный Python | 3.11.9 | 0,002 | 1,451 | 2,168 | 262 символа |
| Ubuntu 24.04, WSL 2, сетевое пространство без внешнего маршрута | 3.12.3 | 0,002 | 0,854 | 1,471 | 262 символа |

Установлены вложенные колёса NumPy 1.26.4 через pip с `--no-index`. В пространстве сети Linux системный вызов `socket.if_nameindex()` показал только loopback; таблица IPv4-маршрутов процесса пуста. В Windows сетевые адаптеры оставались включёнными. Для конкурсного видео остаётся показать отключение внешней сети всего ноутбука и запуск новой сессии. Измеренные максимумы относятся к этим входам и этому ноутбуку.

Для нового процесса с коротким приветствием пик в WSL составил 333 900 КиБ по GNU time. В Windows максимум суммы рабочих наборов процесса и дочерних процессов при опросе каждые 20 мс составил около 343 МиБ. От запуска процесса в Windows до выхода прошло 6,25 с. CPU ноутбука — Intel Core i5-12450H. Для обучения использовалась NVIDIA GeForce RTX 3050 Laptop с 4 ГБ видеопамяти.

Все 19 тестов прошли в WSL в обучающем окружении, включая паритет PyTorch/NumPy для GRU и Transformer. В чистой Windows-среде прошло 17 тестов, ещё два теста паритета были пропущены из-за отсутствия PyTorch. Бот в обеих сериях работал без PyTorch. ## Как менялось качество

Первая сборка версии 2.0 получила 0/27 на закрытой серии, архивная 1.1 получила 2/27. После первого вскрытия задания этой серии считались регрессионными. Финальная оценка дополнительно включила **14 новых** ходов с другими формулировками и отдельную официальную тройку. У этих серий разные назначения, объединять их в один процент не следует. [Исходный независимый протокол](audience-first/README.md)

После доработки на прежних 27 ходах полностью выполнено 1/27, на новых — 0/14. На официальных вопросах получено 2/3 по строгому критерию. Для радуги было названо преломление и отражение, но завершение цитаты упускало различие между цветами. После этой оценки изменено общее правило выбора границы цитаты для вопросов о причинах: программа может включить следующее поясняющее предложение из того же абзаца, если оба помещаются в лимит. При повторном запуске через тот же интерфейс изменилась ровно одна из 44 реплик — объяснение радуги. На последней публичной проверке получено 3/3. Формулировки трёх вопросов были известны во время разработки. [Независимая вторая проверка](audience-second/README.md) · [Проверка официальной тройки после исправления](audience-second/official-after-citation.md) · [Сличение всех 44 реплик](final-replay.json).

В 22 технических пробах «Чем пахнет вторник?» дало «Яблочным пирогом.», а на прямое «Ты бот или человек?» бот ответил «Человек.». На более косвенное «А если наоборот, человек или бот?» он попросил объяснить слово «наоборот». Приём удачной отдельной формулировки не переносится автоматически на похожий разговор.

Короткие приветствия, общие грамматические преобразования, ответы по явно написанным фактам и выбор между указанными вариантами дают рабочие примеры. В неожиданных ситуациях бот часто уточняет уже понятный вопрос, теряет условие или не может обосновать свой выбор. Способность убедить зрителей, что за ширмой человек, пока не проверена в живом голосовании. Уместность ответов на закрытой серии недостаточна для свободного раунда.
