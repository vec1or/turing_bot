# Результаты версии 2.2.0

## Что изменилось по сравнению с 2.1.2

* `reactions.py` — прямая речь об опоздании с учётом условий (кто опоздал, повтор, извинение, предупреждение, время ожидания). На официальный вопрос 3 бот раньше отвечал «Всё в порядке.», теперь принимает извинение и упоминает полчаса ожидания.
* `travel.py` — совет приезжающему: 6 городов (Астана, Алматы, Шымкент, Караганда, Москва, Санкт-Петербург) × 4 сезона, для других городов — по сезону.
* `profile.py` — биография вымышленного студента Тимура (имя, возраст, город, учёба, семья, любимые фильм/книга/музыка, планы), время и дата по локальным часам.
* `goal_plan.py` — доделан и подключён: планы «как не забыть X перед Y» и «как не перепутать A и B».
* Генератор больше не выдаёт ответы короче трёх слов, запасные реплики стали проще и разговорнее, выбор «вариант «сидишь»» больше не повторяется как пункт меню.
* Зависимости pymorphy3/dawg2 из черновика 2.2 удалены: код их не использовал, а установка без интернета на Python 3.12 не работала. Для игры нужен только NumPy.

## Слепая проверка

Независимый агент-проверяющий (Claude) составил 40 вопросов, не читая код, и прогнал их одной сессией на промежуточной сборке 2.2. Приемлемыми (уместность 2, естественность ≥ 1, контекст ≥ 1) он признал **15 из 40**. По категориям: личные 5/8, «ты бот?» 3/6, социальные ситуации 1/5, советы 1/6, объяснения 2/6, мнения и шутки 2/5, продолжения 1/4. Из 40 ответов 15 пришли из запасного набора. Это оценка ИИ, а не людей; человеческое голосование не проводилось.

## Повторный прогон после исправлений (регрессионный, не слепой)

После разбора ошибок те же 40 вопросов прогнаны снова. Запасных реплик стало 8 вместо 15, генератор сработал 1 раз вместо 3. Поскольку исправления делались по этим же вопросам, результат не является новой независимой оценкой. Оставшиеся слабые места: бытовые «почему» вне базы (соль на дорогах, шум чайника, тесто), реплики в ситуациях кроме опоздания (подарок, шумный сосед), просьба повторить первый вопрос, свободная генерация на «А почему именно оно?».
